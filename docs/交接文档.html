1. 项目概览

  • 是什么：Windows 桌面测绘计算工具（PySide6），大地 ⇄ 平面坐标、高程异常、照片 POS、OSGB/LAS/CAD 批处理。
  • 形态：单进程 GUI；重活丢 QThread（app/gui/workers.py），UI 线程只画界面。
  • 数据：全部是文件，没有数据库——params/*.json（参数）、models/（格网）、logs/operation_log.jsonl（台账）、logs/crash_*.log（崩溃）。
  • 打包：PyInstaller onedir（GeoRefine.spec）+ tools/make_release.py 组装免安装版。

关键约定（改代码前必读）

1. 角度：core/* 内部一律弧度；只有 GUI 输入输出层用度或 d.ms。ecef_to_geodetic() 返回的是度（历史约定），转弧度要显式 math.radians。 2. 平面坐标：x=北、y=东（与 CAD 的 X东/Y北相反，cad/dxf_transform.py 里有换算矩阵）。 3. 加常数 x0/y0 单位 km，投影面大地高 h0 单位 m。 4. 模型可见 ⟺ 可复现：写进结果表的东西要能从参数文件重建。 5. 表格：一律用 pages._CopyTable（v1.2 起），不要直接用 QTableWidget，否则丢 Ctrl+C。 6. 弹窗：用 _quiet_info / _quiet_warn（测试里会被替换成空函数）；自动重算路径用 self._auto 抑制弹窗。 7. 异常：页面槽函数里的异常会被全局钩子记进 logs 并弹窗；不要用 except: pass 把计算错误吞掉（v1.2 修的就是这类问题）。

2. 跑起来

# 依赖
pip install -r requirements.txt

# 运行
python main.py

# 全量测试（约 1 分钟；DWG 那条会尝试驱动本机 AutoCAD，忙时自动跳过）
$env:PYTHONIOENCODING='utf-8'; $env:QT_QPA_PLATFORM='offscreen'; python run_tests.py

# 打包 exe（约 70 秒）
python -m PyInstaller GeoRefine.spec --noconfirm --clean

# 组装免安装版 + zip（会先删并重建 dist/GeoRefine-免安装版-vX.Y/）
python tools/make_release.py --skip-build

# 文档转 HTML
python tools/build_docs_html.py
make_release.py 会 rmtree 免安装目录：如果里面有你手动放的 models/、params/、logs/，先备份。

3. v1.2 改了什么（相对 v1.1）

新增

  • 全表格 Ctrl+C 复制（_CopyTable）：选区/整表 → TSV 剪贴板；输入表右键菜单也有「复制选中单元格」。
  • 全局崩溃钩子（main.py）：未捕获异常写 logs/crash_*.log 并弹窗（打包版没有控制台，以前是"点了没反应"）。
  • 新增 7 个测试文件（复制、崩溃钩子、角度格式、空间转换、DXF 高程、页面回归、数值核心），共 37 项断言。
  • 本手册、交接文档、审查报告；用户手册按当前 UI 全面重写。

修复（18 处，详见 docs/审查报告-v1.2.md）

计算类：七参数 BLH 输出的度/弧度混用、平面高程拟合用错自变量、保存参数写死 CGCS2000 椭球、d.ms 识别缺 ε、子午线弧长两处系数（e⁸ / e¹⁰ 分母）、DXF 仅高程模式漏改 CIRCLE/ARC/INSERT、OSGB 退出码不检查、SRSOrigin 解析静默变 0。 流程类：照片批处理完成回调 KeyError、照片页缺失的平面参数下拉、控制点导入目标列被覆盖、换带页高程列非数值中断整批、多边形页 b0 取错列、OSGB 页重复 connect、纯高程参数点数恒 0、空 CASS 文件 NameError、DWG 报错信息缺 HRESULT、两处文档字符串非法转义。

6. 接手时的建议路线

1. 先跑 python run_tests.py，确认 25/25 全绿（DWG 那条在 CAD 忙时会跳过）。 2. 读 docs/技术手册.md 的坐标/高程口径与算法依据，再动计算代码。 3. 改 UI 只在 app/gui/pages.py；改算法放 app/core 或 app/logic（保持无 Qt 依赖，方便测试）。 4. 每改一处，补一条 tests/test_*.py 断言；run_tests.py 会自动发现。 5. 发布前：python run_tests.py → pyinstaller → make_release.py → 手工点一遍改动页。 6. 版本号在 app/__init__.py、tools/make_release.py、main_window.py 的侧边栏标签、README.md 四处，改时一起改。
