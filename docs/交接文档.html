1. 项目概览

  • 是什么：Windows 桌面测绘计算工具（PySide6），大地 ⇄ 平面坐标、高程异常、照片 POS、OSGB/LAS/CAD 批处理。
  • 形态：单进程 GUI；重活丢 QThread（app/gui/workers.py），UI 线程只画界面。
  • 数据：全部是文件，没有数据库——params/*.json（参数）、models/（格网）、logs/operation_log.jsonl（台账）、logs/crash_*.log（崩溃）。
  • 打包：PyInstaller onedir（GeoRefine.spec）+ tools/make_release.py 组装免安装版。

关键约定（改代码前必读）

1. 角度：core/* 内部一律弧度；只有 GUI 输入输出层用度或 d.ms。ecef_to_geodetic() 返回的是度（历史约定），转弧度要显式 math.radians。 2. 平面坐标：x=北、y=东（与 CAD 的 X东/Y北相反，cad/dxf_transform.py 里有换算矩阵）。 3. 加常数 x0/y0 单位 km，投影面大地高 h0 单位 m。 4. 模型可见 ⟺ 可复现：写进结果表的东西要能从参数文件重建。 5. 表格：一律用 pages._CopyTable（v1.2 起），不要直接用 QTableWidget，否则丢 Ctrl+C。 6. 弹窗：用 _quiet_info / _quiet_warn（测试里会被替换成空函数）；自动重算路径用 self._auto 抑制弹窗。 7. 异常：页面槽函数里的异常会被全局钩子记进 logs 并弹窗；不要用 except: pass 把计算错误吞掉。

2. 跑起来

# 依赖
pip install -r requirements.txt

# 运行
python main.py

# 全量测试（约 1 分钟；DWG 那条会尝试驱动本机 AutoCAD，忙时自动跳过）
$env:PYTHONIOENCODING='utf-8'; $env:QT_QPA_PLATFORM='offscreen'; python run_tests.py

# 打包 exe（约 70 秒）
python -m PyInstaller GeoRefine.spec --noconfirm --clean

# 组装免安装版 + zip（会先删并重建 dist/GeoRefine-免安装版-vX.Y/）
python tools/make_release.py --skip-build

# 文档转 HTML
python tools/build_docs_html.py
make_release.py 会 rmtree 免安装目录：如果里面有你手动放的 models/、params/、logs/，先备份。

3. v1.3 修复与演进（全量 38 项缺陷闭环，27/27 测试全 PASS）

第一部分：v1.2 遗留修复（10 项）

  • OSGB 放行合法大地源参数并透传投影覆盖。
  • LAS 1.4 写回保留源 EVLR（CRS WKT 等）。
  • LAS 转换异常时清理未完成的残留文件。
  • WSL 顶点改写与原生 C++ 统一采用 u = A @ p + b。
  • Surfer 双精度 GRD 判别支持。
  • 纯数字点名导出再导入列错位修复。
  • 局部平面坐标判定边界收紧。
  • 高斯投影弧长公式注释与基准软件对齐说明。
  • OSGB 任务临时目录即时清理。
  • 自动选型导出四参数 _fit4 正常填充。

第二部分：AST 与代码深度审计（6 项）

  • SpacePage 导入文件 _src_lonlat() AttributeError 崩溃修复。
  • SpacePage / ApplyPage 通用表格导入缺失 read_points_table 导入修复。
  • file_jobs.py CAD/SHP 转换输出坐标轴颠倒（东/北互换）重大数学错误修正。
  • 精度对比页表头大写 H 导入 float 转换异常修复。
  • transform2d.py 冗余重复代码删除。
  • GaussPage 冗余重复方法定义清理。

第三部分：GPT-6 交叉核验新挖出缺陷全面闭环（22 项）

  • 点云与模型：LAS EVLR 写入异常向上冒泡不吞异常；requirements.txt 补齐 laspy[lazrs]>=2.5.0；输入/输出同目录或嵌套目录循环处理递归拦截；OSGB 进程轮询与取消即时终止；LAS 大坐标 32 位整数溢出自动偏移。
  • 高程拟合计算时序：CASS .dat、DXF 块与圆弧、PGDB 要素类高程拟合自变量全部严格固定为源坐标 (x_src, y_src)，避免在平面变换后坐标上求值。
  • GIS 与图形格式：Shapefile 针对 3D/带 M 要素（PolylineZ、PolygonZ、MultiPointZ）采用标准三维写入接口，杜绝类型不匹配并完整保留 Z 坐标与 M 属性；Surfer DSBB 二进制网格与 DSAA ASCII 网格原生解析；不规则格网步长一致性阈值收紧至 1%。
  • 坐标系统与数学核心：跨椭球七参数/三参数转换增加目标椭球 ell_dst 记录与反算，彻底消除跨基准产生的 ~108 米高程系统偏差；通用导入器引入标准 csv.reader 正确处理引号内逗号，且通过 math.isfinite 严格拦截 nan/inf；.ipj 打开前验证文件存在性防止空文件生成。
  • 流程与健壮性：照片批处理根目录父子包含去重；同名输出文件递增编号防覆盖；各文件转换取消时即时清理磁盘残余半成品；主窗口关闭时全量通知后台 Worker 停止并等待安全退出。

5. 接手时的建议路线

1. 先跑 python run_tests.py，确认 28/28 全绿（DWG 那条在 CAD 忙时会跳过）。 2. 读 docs/技术手册.md 与 docs/审查报告-v1.3.md 的坐标/高程口径与算法依据，再动计算代码。 3. 改 UI 只在 app/gui/pages.py；改算法放 app/core 或 app/logic（保持无 Qt 依赖，方便测试）。 4. 每改一处，补一条 tests/test_*.py 断言；run_tests.py 会自动发现。 5. 发布前：python run_tests.py → pyinstaller → make_release.py → 手工点一遍改动页。 6. 版本号在 app/__init__.py、tools/make_release.py、main_window.py 的侧边栏标签、README.md 四处，改时一起改。
