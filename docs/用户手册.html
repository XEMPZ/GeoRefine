GeoRefine 用户手册

似大地水准面精化与坐标转换软件 v1.2

本手册按「装上就能用」的顺序写：先看第 3 节五分钟上手，遇到具体功能再翻第 5 节的对应页面。 技术口径（公式、算法依据、数据格式）见同目录《技术手册.md》。

1. 这个软件能做什么

一个本地运行的测绘计算工具，覆盖「大地坐标 ⇄ 施工平面坐标 ⇄ 模型/照片」这条链路上的常见活。

页面一句话
首页功能导览 + 当前环境自检（模型/参数/台账数量）
高斯投影换带单点的高斯投影正反算与换带（支持 UTM 尺度、加常数、抵偿投影面）
空间坐标转换XYZ / BLH / xyH 六种形式两两互转
参数应用转换用参数库里保存好的参数，批量转换一份坐标清单
控制点转换导入公共点对，自动比选所有可行方案，挑最优的存进参数库
照片 POS 处理把无人机照片里的 POS 大地高换成正常高并写回照片（免相控）
OSGB 模型转换倾斜摄影 OSGB 模型逐顶点坐标/高程转换
点云模型转换LAS/LAZ 点云逐点坐标/高程转换，其它维度原样保留
多项式转换二维/三维多项式拟合（复杂坐标系的补充手段）
文件转换整个文件夹的 CAD（DXF/DWG）、SHP、文本点文件按参数批转
精度对比同一批点对喂给两套参数，逐点比残差，告诉你该用哪个
参数库管理算好的参数与自定义椭球，可导入导出、直接拷贝
处理台账每次计算/回写/转换都留痕，可导出 CSV
关于本软件版本、仓库地址、BUG 反馈

三条主线：

1. 单点换算：换带页 / 空间转换页，贴几个点就算。 2. 批量算参数：控制点转换页 → 存参数库 → 参数应用 / 照片 / 模型 / 文件转换都用它。 3. 批处理回写：照片 POS、OSGB、LAS、CAD 四类，都有台账和回滚。

2. 安装与启动

2.1 免安装版（推荐给使用者）

双击 GeoRefine.exe 即可，无需安装 Python。

目录结构（dist/GeoRefine-免安装版-v1.2/）：

路径作用
GeoRefine.exe主程序
_internal/Python 运行时与依赖（勿删）
models/大地水准面格网（自带 EGM96，中国区域高精度格网自行放入）
params/转换参数 JSON（自己算的、别人给的都是 JSON 文件，拷进来即可）
native/OSGB 原生转换器（勿删；缺了 OSGB 页会提示）
logs/操作台账 + 崩溃日志
docs/用户手册、技术手册
src/完整源代码（可自行修改、可用任何 AI 工具改）
config.json可选开关（如 enable_poly3d）
免安装版把 models/ params/ logs/ 放在 exe 旁边而不是临时目录，重启后参数库与格网仍在。

2.2 源码运行（开发）

pip install -r requirements.txt
python main.py

依赖：PySide6、numpy、Pillow、piexif、ezdxf、laspy、tifffile + imagecodecs（读 GeoTIFF 格网）、pyproj（仅验证工具用）。

2.3 系统要求

Windows 10/11 64 位。DWG 转换需要本机装有 AutoCAD（COM 自动化）；OSGB 转换需要 native/osgb_vertex_transform.exe 或 WSL + OpenSceneGraph。

3. 五分钟上手

3.1 只算一个点（高斯投影换带）

1. 左侧点【高斯投影换带】。 2. 「转换前投影参数」填中央子午线（如 114，d.ms 编码下 114 度就是 114）。 3. 「输入源坐标」选 大地坐标 + d 格式，表格里填 B=25.905919、L=114.973155。 4. 点【转换】，右侧出 x/y；点【保存结果】存 CSV。

表格里 回车 自动增行、Ctrl+V 可整块粘 Excel、Ctrl+C 可把选区复制回别处。

3.2 用一组公共点算参数（控制点转换）

1. 点【导入点对文件】（支持 GNSS 手簿 .cot、南方 CASS 点对、CSV/TXT/XLSX）。 2. 确认表里 源 与 目标 两类坐标都对（源=GNSS 坐标，目标=施工坐标）。 3. 点【计算与比选】，等右侧「方法」表出来，按 RMS 从小到大排。 4. 勾选最合适的那一行 → 点【保存所选方法到参数库】，给它起个名字。

3.3 把参数用到照片上（照片 POS 免相控）

1. 【照片POS处理】→【添加目录】→【扫描照片】。 2. 「高程转换方式」选刚才存的参数（或格网模型、或常数偏移）。 3. 先点【计算】看预览：每张照片的处理前高程、ξ、处理后高程都在表里，这一步不写盘。 4. 确认无误点【开始处理】：首次会在 _POS备份/ 保存原图，然后回写 EXIF/XMP。 5. 出问题点【从备份回滚】，照片恢复原样。

4.2 角度格式

两个选项，只影响"含经纬度"的一侧：

  • d 格式（十进制度）：25.905919 就是 25.905919°。
  • d.ms 格式（度.分秒编码，手簿惯例）：D.MMSSssss，30.26345678 = 30°26′34.5678″；分固定两位，秒随输入精度；负角整体取负。

批量转换页的「自动」模式会按数值结构判断：分/秒位出现 ≥60 的值必是十进制度。

输入框里也认 30 26 34.5678 这种空格或 °′″ 分隔的写法。

4.3 坐标与高程口径

  • 平面坐标 x = 北坐标、y = 东坐标（y 通常含 500 km 假东、或带号前缀），与手簿/成果表一致。
  • 大地坐标 B = 纬度、L = 经度。
  • 高程：大地高 H（椭球面起算，GNSS 直接给）与正常高 h（水准面起算，工程用）。

高程异常 ξ = H − h；高程转换即做 h = H − ξ。

  • 投影参数单位：中央子午线与平均纬度用 d.ms；加常数 x0/y0 用 km；投影面大地高 h0 用 m。
  • 「严密工程椭球 / 近似工程椭球」：抵偿投影面时长半轴怎么放大——近似 a+h0（行业惯例），严密 a·(1+h0/Ra(B0))。

4.4 带号

平面 y ≥ 1000 万时按含带号处理：13–23 为 6° 带（L0 = 6n−3），24–45 为 3° 带（L0 = 3n）。其余带号不自动识别，需手填中央子午线。

5. 逐页说明

5.1 首页

功能导览 + 右上「当前环境」自检：格网数、参数数、台账条数、原生转换器是否存在。点各块的【打开 →】直接跳到对应页。

5.2 高斯投影换带

单点/小批量的大地 ⇄ 平面换算，或换带（不同中央子午线之间）。

1. 选椭球（内置 WGS84/CGCS2000/Beijing54/Xian80，或参数库里的自定义椭球）。 2. 「转换前投影参数」：中央子午线、x0、y0、投影面大地高、UTM k、平均纬度（严密模式用）。 3. 「输入源坐标」选 平面/大地 与角度格式，填点号与三列坐标。 4. 【转换】→ 右侧结果；【保存结果】导出 CSV。

源是平面坐标时，软件用「转换前」那套投影参数反算大地坐标，再用「转换后」那套正算——这正是换带的用途。 第 4 列（高程）不参与换算，原值带出；填了非数字也照原样输出并给出提示，不会中断整批。

5.3 空间坐标转换

XYZ（空间直角）/ BLH（大地）/ xyH（平面+大地高）七种转换类型任选其一：

类型用途
BLH → BLH只是角度表现形式互转（d.ms ⇄ d）
XYZ → BLH三维无约束平差成果转经纬度
XYZ → xyH一步到位到平面
BLH → XYZ反算
BLH → xyH最常用：GNSS 坐标 → 施工坐标
xyH → XYZ / xyH → BLH平面成果反算

输入三列：点号 + 两个必需列 + 第三列。源为 BLH/xyH 时第三列是大地高，可留空（按 0 计）；源为 XYZ 时第三列是 Z，必须填。

5.4 参数应用转换

拿参数库里的参数批量转换坐标。

1. 「选择参数」下拉选一个（旁边有刷新 / 打开参数文件夹 / 删除）。 2. 表格按参数期望的源类型自动改表头；可直接粘贴或【读入源文件】。 3. 勾选「转换平面坐标 / 转换高程」决定转哪几样；「自动识别」判断源是大地还是平面。 4. 【转换】→ 结果表；【保存结果】导出。

5.5 控制点转换（算参数的地方）

1. 导点对：支持 .cot（GNSS 手簿点校正）、南方 CASS 公共点、南方坐标转换软件点对、CSV/TXT/XLSX。 列序：点名,源x(或L),源y(或B),源h(或H),目标x,目标y,目标h；「用平面」「用高程」两列决定该点参与哪种解算。 2. ① 椭球与投影参数：选原始/目标椭球；源是工程平面坐标时填源侧投影（用于反算大地坐标）；目标侧同理。 3. ② 平面转换：勾选允许参与比选的方法——四参数、三参数、七参数（源为大地坐标时自动走「七参数+投影+四参数」的链式）、同椭球高精度二维。 4. ③ 高程转换：同椭球高精度大地高↔正常高、平面拟合、曲面拟合、大地水准面模型（可与拟合串联：ξ = 格网 + 残差趋势）。 5. 点【计算与比选】：右侧表列出所有可行方法的点数、RMS 平面/高程、LOO 高程，按精度排序。 6. 勾选一行 → 【保存所选方法到参数库】。

每个环节旁的【计算】按钮只算那一块，用来单独检查。

5.6 照片 POS 处理（免相控）

把照片 EXIF 的 GPS 大地高换成正常高。

1. 【添加目录】可加多个 → 【扫描照片】统计张数。 2. 「方式」四选一：格网模型 / 拟合参数 / 常数偏移 /（参数库里的其他高程方式）。 3. 勾选「同时更新 XMP AbsoluteAltitude」同步 DJI 的 XMP 高度； 勾选「同时转换平面坐标」并选「平面参数」，可把经纬度同时算成地方平面坐标写进台账。 4. 【计算】= 预览（不写盘）；【开始处理】= 真写盘。 5. 结果表逐张显示 处理前 / ξ / 处理后 / 状态（ok、no_pos、out_of_range、write_failed、预览）。

安全机制：首次处理时把原图复制到 _POS备份/（保持相对路径），之后不再覆盖备份；【从备份回滚】可整目录还原。每次处理写一份 POS处理台账_时间.csv。

5.7 OSGB 模型转换

倾斜摄影模型逐顶点的坐标/高程转换，SRSOrigin 语义保持不变（顶点承载世界坐标位移），转换后的模型可直接在原有引擎里加载。

1. 「模型目录」选 Data 那层（含 metadata.xml），「输出目录」另选一个（不允许与模型目录相同）。 2. 「参数」选参数库里的；「转换内容」勾平面/高程。 3. 「源侧投影」：平面坐标含带号、或参数没配源侧投影时必填，可点【从模型自动识别】读 metadata。 4. 「高级」：线程数、输出编码（压缩 ~0.8–1.7× / 仅几何压缩 / 不压缩 ~3.8×）。 5. 【检查】自检（原生转换器、瓦片数、参数适用性），再【开始转换】。

常见失败：原生转换器缺失（native/ 没了）、模型目录没有 .osgb、参数源类型不符、CAD/系统占用输出目录。失败时不会写 metadata.xml，输出目录可直接删掉重来。

5.8 点云模型转换

LAS/LAZ 逐点转换 X/Y/Z，强度、回波、分类、GPS 时间、RGB 一律原样保留。

1. 选点云目录与输出目录（可勾「递归子目录」）→【扫描】。 2. 选参数、勾转换内容；平面坐标含带号或参数源为大地坐标时填源侧投影（可【从 LAS 头自动识别】）。 3. 【开始转换】。

已知限制：LAS 1.4 把 CRS 放在 EVLR 时，输出文件的 EVLR 会丢（坐标本身正确）。

5.9 多项式转换

二维/三维多项式拟合（南方口径固定 2 阶；1/3 阶为本软件扩展）。

1. 导入点对或手填（源 3 列 + 目标 3 列）。 2. 选「二维/三维」与阶数；源/目标是普通平面时填对应坐标系（用于和大地坐标互换）。 3. 「高程处理」可叠加：由多项式第三分量 / 曲面拟合 / 大地水准面模型 / 不计算。 4. 点【拟合并保存到参数库】。

5.10 文件转换

把整个文件夹的 CAD（DXF/DWG）、SHP、PGDB、文本点文件按参数批量转换。

1. 【选择文件】或【增加文件夹】（可多次追加，支持子目录扫描）。 2. 「平面参数」「高程方式」（不转换 / 参数 / 常数偏移）。 3. 勾「2D实体也写高程(elevation)」时，二维多段线等按整体高程平移。 4. 【开始转换】→ 逐文件进度，每个文件一行结果。

DWG 需要本机 AutoCAD：软件通过 COM 让 AutoCAD 另存为 DXF 再处理。若 AutoCAD/CASS 正忙（执行命令、有模态对话框、正在编辑图纸），会等待约 60 秒后报错——把 CAD 让出来或关掉图纸再试。DXF 不需要 CAD。

5.11 精度对比

同一批点对喂给两套参数，逐点比残差。

1. 【导入点对文件】（要有目标坐标）。 2. 选「参数 A」「参数 B」，勾「对比坐标 / 对比高程」。 3. 【计算对比】→ 表格给出两套参数的 RMS、平均、最大值；【导出 CSV】存档。

5.12 参数库

三块：自定义椭球、坐标转换参数（JSON）、大地水准面文件（models/）。

  • 【查看 JSON】可直接看到参数结构，方便核对/手改。
  • 【导入南方方案(.ipj)】把南方 CASS 的方案文件转成软件参数。
  • 【打开存放文件夹】直接在资源管理器里拷贝——参数是纯 JSON，给别人就是发个文件。

5.13 处理台账

每次计算、回写、转换都记一行（时间、操作、摘要、详情）。【导出 CSV】存档，【清空记录】清屏（不影响已生成的结果文件）。

原始台账在 logs/operation_log.jsonl，一行一个 JSON。

版本号、GitHub 仓库（源码/发行版/问题反馈）、BUG 邮箱。反馈时请附：操作步骤、数据样例、版本号。

6. 参数文件结构（coordparam/1）

params/某参数.json：

{
  "schema": "coordparam/1",
  "name": "0927_2144_chain74",
  "kind": "chain74",
  "source_kind": "lonlat",
  "target_kind": "planar",
  "ellipsoid": "CGCS2000",
  "projection":   { "l0": 105.0, "x0": 0.0, "y0": 500000.0, "k": 1.0, "h0": 0.0, "rigorous": false, "b0": 30.0, "zone": 35, "band": "3度带" },
  "projection_src": { ... },
  "planar4": { "dx": 1234.5, "dy": -678.9, "a": 0.99999, "b": 1e-5 },
  "seven":   { "dx": 1.2, "dy": -3.4, "dz": 5.6, "rx_s": 0.001, "ry_s": 0.0, "rz_s": 0.0, "scale_ppm": -1.2 },
  "three":   { "dx": 1.2, "dy": -3.4, "dz": 5.6 },
  "heightfit": { "mode": "plane", "space": "planar", "value_type": "xi",
                 "coef": [0.0, 0.001, 0.002], "center": [x0, y0], "loo_rms": 0.012 },
  "use_geoid": false,
  "accuracy": { "n_points": 12, "rms_xy_m": 0.008, "rms_h_m": 0.013, "loo_rms_h_m": 0.015, "note": "" },
  "points_used": ["G1", "G2", "..."],
  "created": "2026-10-24T16:00:00"
}
  • kind：planar4 / planar3 / seven / three / chain74 / direct_gk / seven2d / poly3d / inv_*（逆向链）。
  • source_kind / target_kind：lonlat（大地）或 planar（工程平面）。
  • heightfit.value_type：xi（求的是高程异常，h = H − v）或 dh（求的是改正数，h = H + v）。
  • heightfit.space：planar 用平面坐标拟合，lonlat 用经纬度拟合；自变量永远是"源"坐标。

7. 大地水准面模型

放到 models/，软件按扩展名自动识别：.gtx / .tif / .csv / .zgf / .ggf / .grd。

  • 免安装版自带 EGM96（15′），精度约 0.5 m 级，够一般工程。
  • 中国区域高精度格网（省级 CQG/似大地水准面）请自行放入 models/。
  • 超出格网范围会直接报错拒绝，不做外推（这是刻意的：外推出来的是假数据）。

8. 常见问题

现象原因与处理

提示"没有可转换的数据"前两列坐标没填；或 XYZ 源第三列 Z 空着
