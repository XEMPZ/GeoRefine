# GeoRefine 用户手册
似大地水准面精化与坐标转换软件 v1.0

## 1. 安装与启动

要求：Windows 10/11，Python 3.10+（建议 3.13）。

```powershell
# 在项目目录 geoid_suite 下
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python main.py
```

依赖：PySide6（界面）、numpy（解算）、Pillow + piexif（照片元数据）、ezdxf（DXF）、tifffile + imagecodecs（可选，读 GeoTIFF 格网）。

## 2. 坐标与高程口径（重要）

- 平面坐标 **x=北坐标、y=东坐标**（y 含 500 km 假东偏移），与 GPS 手簿、控制点成果表一致。
- 大地坐标 **B=纬度、L=经度**（单位：度）。
- 高程：**大地高 H**（椭球面起算，GNSS 直接测得）与**正常高 h**（水准面起算，工程用高程）。
  高程异常 **ξ = H − h**；软件的高程转换即求 ξ 并做 **正常高 = 大地高 − ξ**。

## 3. 控制点转换页

1. 在表格中手动输入控制点对，或点【导入 CSV/TXT】。列格式：`点名,源x(或L),源y(或B),源h(或H),目标x(或L),目标y(或B),目标h(或H)`，支持 `#` 注释行、逗号/制表符分隔、UTF-8/GBK 编码。
2. 点【自动比选并计算】。软件自动识别坐标类型（平面/大地）并计算所有可行方法：
   - **planar4** 平面四参数（适合小测区，经验上 ≤50 km²）
   - **seven** 空间七参数·布尔莎（跨基准、大范围）
   - **chain74** 七参数+高斯投影+四参数（源大地坐标 → 地方平面坐标系，中央子午线自动按 3° 带选取）
   - **direct_gk** 直接投影基线（用于检查两套坐标是否本就同基准）
   - 高程方案：固定差 / 平面拟合 / 二次曲面拟合，按**留一交叉验证（LOO）RMS** 自动定阶；拟合面中心点取**最后一个控制点**，与中海达 GNSSTools 手簿口径一致。
3. 对比表中 ★ 为自动选中方法（RMS 最小）；下方明细区显示参数值与精度。
4. 输入参数名 →【保存所选方法到参数库】。参数为 JSON 文件，存于 `params/`，可在照片POS、CAD、精度对比各页直接调用。

精度说明：RMS 为控制点残差均方根；点数恰好等于参数个数时无检核条件（软件会标注），建议平面 ≥4 点、七参数 ≥4 点、二次曲面 ≥7 点。

## 4. 照片 POS 处理页（核心功能）

1. 【选择目录】→【扫描照片】：递归统计目录及**全部子目录**中的 JPG（自动跳过备份目录）。
2. 选高程转换方式：
   - **格网模型**：`models/` 下的大地水准面格网（EGM96 已内置；EGM2008 可下载；可导入局部格网，见 §8）；
   - **拟合参数**：参数库中带高程拟合（经纬度空间）的参数；
   - **常数偏移**：统一加一个常数。
3. 【开始处理】：逐张提取 POS（EXIF GPS 优先，兼容大疆 XMP 的 AbsoluteAltitude/RelativeAltitude），转换高程后**回写 EXIF GPSAltitude**（可选同步更新 XMP）。后台线程执行，进度条实时显示，【取消】随时中止。
4. 每张照片写前自动备份到 `<目录>\_POS备份\`（镜像原目录结构，仅首次备份）。台账 CSV（UTF-8-BOM，Excel 可直开）逐张记录：文件、经纬度、处理前椭球高、转换值、处理后高程、状态、备份路径。
5. 【从备份回滚】：从 `_POS备份` 一键还原全部照片。

状态说明：`ok` 成功；`no_pos` 照片无 GPS 元数据；`out_of_range` 位置超出格网覆盖；`write_failed` 写入失败；`skipped` 用户取消。照片影像像素不会被修改，仅元数据。

> EXIF 高程按 1 cm 栅格存储（rational 分母 100），台账中记录的是全精度值。

## 5. CAD 转换页

1. 【选择文件】支持多个 DXF（R12~R2018）。**DWG 需先在 CAD 中另存为 DXF**（软件会自动识别并提示）。
2. 平面转换：选参数库中的四参数（含"七参数+投影+四参数"链式参数）；可不转平面。
3. 高程转换：选参数库中的高程拟合参数（平面空间）或常数偏移；可不转高程。`2D实体也写高程` 选项会对 LWPOLYLINE 写入 elevation。
4. 【输出目录】→【开始转换】。输出文件名 `原名_转换后.dxf`，不覆盖原件；报告显示每个文件的实体变换数与未支持类型。

实体支持：LINE、LWPOLYLINE、POLYLINE(2D/3D)、CIRCLE、ARC、POINT、TEXT、MTEXT、SPLINE、ELLIPSE、3DFACE、SOLID、INSERT（整体变换，块定义不动）、HATCH 等；图层、线型、文字内容、扩展数据全部保留。INSERT/圆弧类实体按"位置+旋转+缩放"精确换算（旋转角随四参数自动叠加，半径随尺度缩放）。

## 6. 精度对比页

1. 【加载 CSV】：对比点格式 `点名,lon,lat,H_ell,H_normal`（`sample_data/精度对比样本.csv` 为样例）。
2. 勾选模型列表中的多个大地水准面（EGM96 / EGM2008 / 局部格网…），可再叠加参数库拟合方案。
3. 【计算对比】：输出每方案的点数、RMS、平均、最大、最小残差，并绘制 RMS 条形图。
4. 【导出 CSV】/【导出 HTML 报告】：HTML 报告自包含样式，可直接存档或分享。

## 7. 参数库与处理台账

- **参数库页**：查看 JSON 明细、删除、刷新。所有页面共用 `params/` 目录。
- **台账页**：每次参数计算/保存/删除、照片批处理/回滚、CAD 转换、精度报告均写入 `logs/operation_log.jsonl`（时间、输入、参数、结果），可导出 Excel 兼容 CSV。**全部转换任务可追溯**。

## 8. 大地水准面模型管理

软件按扩展名自动识别 `models/` 下的格网：

| 格式 | 说明 | 获取 |
|---|---|---|
| `.gtx` | PROJ 标准二进制（大端），EGM96 内置（4.2 MB，全球 0.25°） | 随包附带 |
| `.tif` | GeoTIFF，EGM2008 2.5′（约 80 MB） | `python tools/download_geoid_models.py`（需 tifffile+imagecodecs） |
| `.csv` | 文本格网 `lon,lat,ξ`，规则格网 | 局部似大地水准面成果（客户项目常用） |
| `.zgf/.ggf/.grd/.bin` | 中海达 ZGF / 天宝 GGF / Surfer GRD / Geoid99 二进制 | 手簿随机光盘或厂商提供 |

导入自定义格网：把文件复制进 `models/` 后在相关页点【刷新】即可。注意格网覆盖范围，超范围的照片会标记 `out_of_range`。

## 9. 常见问题

- **界面卡死？** 所有批量任务都在后台线程执行并有进度与取消；如遇极端情况请反馈日志。
- **照片 no_pos 多？** 部分无人机未开 GPS 记录，或照片被微信/压缩包转存丢失元数据；用原片。
- **ξ 是负数？** 正常，我国大陆 ξ 多在 −40~+20 m 之间（EGM96 下武汉约 −8 m）。
- **参数与其他软件不一致？** 四参数平移量与尺度/旋转在数学上强相关，绝对值可能差异较大，但区域内转换结果一致（mm 级），以转换后坐标为准。
- **想要 EGMAP/EGM2008 精度更高？** 2.5′ EGM2008 分辨率约 5 km，小测区建议用当地精化格网（CSV/ZGF 导入）或控制点拟合。
- **投影适用范围？** 高斯投影 6 阶级数适用于中央子午线 ±1.5° 内（3° 带内，亚毫米级）；离中央子午线更远请换带（软件自动按 3° 带选 L0）或使用"七参数+投影+四参数"链式方案（自动选带）。

## 10. 样例数据

`sample_data/` 内置全套可复算样例（控制点对、含 POS 照片、DXF、格网、精度对比点），真值参数见 `sample_data/README.md`；一键重新生成：`python tools/make_sample_data.py`。
