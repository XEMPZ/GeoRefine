# GeoRefine v1.2 代码审查报告

审查范围：`app/` 全部 59 个模块（约 800 KB Python），外加一轮数值对勘（pyproj / Karney 精确积分）与 GUI 级回归（offscreen）。
方法：静态扫描（AST：裸 except / except-pass / 可变默认值 / assert）+ 逐模块读码 + 构造输入实测复现。
结论：**修 18 处**（其中 9 处会算出错数据、4 处会崩或丢结果），**另有 10 处已定位但未改**，列在第 3 节。

---

## 3. 已定位、未修改（10 项）

见《交接文档.md》第 4 节的表（位置、问题、建议改法一一对应）。简述：

1. OSGB 页「大地源参数」功能不可达（提示与 `do_run` 自相矛盾，引擎其实支持）。
2. LAS 输出丢 EVLR（LAS 1.4 的 CRS WKT）。
3. LAS 失败/取消不删半成品文件。
4. `_wsl_rewrite.py` 的 `b/origin` 口径与 C++ 不一致（该函数当前无 GUI 调用点）。
5. `geoid.read_grd` 的 f32/f64 判别不可达（需造 f64 样例复现）。
6. `pair_io` 纯数字点名导出再导入会错位一列。
7. `detect_coord_kind` 以 |v|≤360 判经纬度，局部小坐标会误判。
8. `gk_engine` 级数缺 sin8φ 项，留 31 µm（0.03 mm）残差。
9. `flash.py` 的 mkdtemp 目录不清理。
10. `autoselect.build_param_dict` 依赖从不写入的 `row["_fit4"]`（仅测试路径）。
